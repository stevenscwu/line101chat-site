# LINE101 AI分身費用原則

## 正式回答

目前不提供未經評估的固定 AI分身價格。標準回答為：

「需依知識庫大小、串接系統、回覆通道與是否私有部署評估。」

## 評估因素

主要因素包含文件數量與品質、Google Drive 或網站同步方式、LINE Messaging API 串接、網站元件、語音需求、權限、紀錄、維護頻率、模型用量，以及是否需要 Ollama、本地端或私有部署。

## 建議下一步

先選一個明確使用情境，準備現有 FAQ、PDF、網站或 SOP，並說明偏好通道與預計使用者。LINE101Chat 團隊可先做免費評估，再提出 MVP 範圍與正式報價。
